

### ESP32

### OLED
- GND - МинусШина
- VDD - пятерка с 3V3

- SDA - D21


### IR_reciever

- (L с минусиком) c1(gnd) c2(pwr) c3(out) (R)
- c1 - МинусШина
- с2 - пятерка с 3V3
- с3 - D4
